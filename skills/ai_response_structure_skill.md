# AI 结构化与精准搜索链接 Skill 规范 (AI Structured Markdown Skill)

本 Skill 旨在统一和规范 CerealsNS 智能聚合搜索中 AI 大模型（Gemini / OpenRouter / DeepSeek / Claude）的回答输出格式，强制使用极简、美观、嵌入精准搜索引证与标准 Markdown 格式，让用户以最高效率直观获取关键信息并一键跳转原始数据源。

---

## 核心设计与精准链接原则 (Core Principles)

1. **标准数字引证标注 (Standard Citation Badges)**：所有要点、数据和结论必须带上精准数字引证 `[1]`, `[2]`, `[3]`，并由前端渲染器自动关联并高亮对应的原始网页搜索结果卡片。
2. **默认全量 Markdown 格式 (Strict Markdown Default)**：所有回答必须使用标准 Markdown 语法，包括 `#` / `##` / `###` 标题、`-` / `1.` 列表、`**` 加粗重点、`|` 表格与 `` `code` `` 代码块。
3. **段落间保留标准空行 (`\n\n`)**：标题、段落、分隔线（`---`）、列表与表格之间必须包含完整的双换行符（空行），禁止把标题与正文紧贴在同一行。
4. **结论先行 (Conclusion First)**：顶层使用 `### 📌 一句话结论`，用 1-2 句精炼文本给出最终答案，避免冗长的套话开场。
5. **表格化呈现 (Markdown Tables)**：涉及到多项对比、参数对比、版本区别、方案优缺点时，强制使用标准 Markdown 表格。
6. **权威来源与精准链接汇总 (References Section)**：末尾统一提供 `### 🔗 权威来源与精准网页链接` 列表，采用标准 `[1] [网页标题](精准URL)` 格式，点击可直接打开真实网页。
7. **行动向导 (Actionable Next Steps)**：末尾统一提供 3 个最具启发性的后续延伸追问。

## 标准 Markdown AI 响应结构模板 (Standard Response Template)

```markdown
### 📌 一句话结论
[此处用 1-2 句话给出最直接、精炼的回答结论，并附带引证序号如 [1]]

---

### 💡 核心要点 (Key Takeaways)
- **[要点 1]**：[具体描述与关键数据分析] [1]
- **[要点 2]**：[核心机制或原因拆解] [2]
- **[要点 3]**：[未来趋势或重要注意事项] [3]

---

### 📊 关键信息 / 方案对比 (如适用)
| 对比维度 | 方案/对象 A | 方案/对象 B | 核心建议与引证 |
| :--- | :--- | :--- | :--- |
| **关键特性** | 特性 A | 特性 B | 选择建议 [1] |
| **适用场景** | 场景 A | 场景 B | 选择建议 [2] |

---

### 🔍 深度拆解与精准剖析
#### 1. [子主题 A]
[简明扼要的详细说明，使用加粗强化关键概念与引用 [1]]

#### 2. [子主题 B]
[逻辑严密的分步操作或原理阐述 [2]]

---

### 🔗 权威来源与精准网页链接
- [1] [网页标题 1](https://exact-url-1.com) — 来源站点 / 说明
- [2] [网页标题 2](https://exact-url-2.com) — 来源站点 / 说明
- [3] [网页标题 3](https://exact-url-3.com) — 来源站点 / 说明

---

### 🎯 推荐追问 (Follow-up Questions)
- **追问 1**: [关于进一步优化的延伸问题]
- **追问 2**: [关于对比方案的深度探究]
- **追问 3**: [关于实际落地的实施路径]
```

## 预设 Skill 模式 (Skill Modes)

| Skill 模式 | 适用场景 | Markdown & 精准链接要求 |
| :--- | :--- | :--- |
| **直观极简 (Intuitive & Concise)** | 快速查找事实、概念释义 | `### 📌 结论` + `### 💡 带精准链接要点` + `### 🔗 网页链接` |
| **深度对比 (Structured Comparison)** | 选型、评测、方案决策 | `### 📌 结论` + `### 📊 带链接对比表` + `### 🔗 网页链接` |
| **技术研报 (Technical Analysis)** | 编程、架构、学术追溯 | `### 📌 结论` + 带精准链接原理解析 + `### 🔗 网页链接` |
